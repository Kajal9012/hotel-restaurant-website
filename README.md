# 🍽️ Hotel & Restaurant Website

A professional **frontend Hotel & Restaurant website** developed using **HTML, CSS, and JavaScript**. This project follows a clean folder structure and includes multiple pages related to hotel services, restaurant menu, bookings, policies, and customer support.


## 📌 Project Overview

This project represents a complete hotel and restaurant website interface. Users can explore hotel details, view menus, book rooms or tables, read policies, and contact support. The website is designed with usability, clarity, and real-world structure in mind.

## 🛠️ Technologies Used

* **HTML5** – Semantic structure and multi-page layout
* **CSS3** – Styling, layout, and responsive design
* **JavaScript** – Form handling and client-side interactivity


## ✨ Features

* Multi-page hotel & restaurant website
* Hotel information and restaurant menu pages
* Room booking and table reservation pages
* Separate policy pages (privacy, terms, cancellation, reservation)
* FAQ and help/support pages
* Organized CSS and JavaScript files per feature
* ASO (Additional Styling & Optimization) for better UI and performance

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open the `frontend/hotel.html` file in any modern web browser
3. Navigate through different pages using the menu

## 🎯 Purpose of the Project

* Practice frontend web development with a real-world structure
* Learn multi-page website organization
* Improve skills in HTML, CSS, and JavaScript
